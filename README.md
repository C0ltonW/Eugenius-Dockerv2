Eugenius-Dockerv2
=================

Lightweight, profile-based Docker orchestration for Magento development. This repo boots a modular stack (PHP-FPM, DB, Search, optional Nginx and Redis) with a zero-config first-run experience and clear, editable defaults.

Key Features
------------
- Profiles: minimal (php, db, search) and full (php, db, search, nginx, redis)
- First-run safety: generates .env and Nginx config when missing
- Hybrid configuration model: templates-first, constants-fallback
- Simple, dependency-light Python code; readable and short modules
- Tiny PHP stub (./src/index.php -> phpinfo()) to validate wiring fast
- Search flavor auto-handling (OpenSearch vs Elasticsearch) and JVM opts mapping
- Inline comment stripping for unquoted values in .env (quoted values preserve '#')

Requirements
------------
- Docker Desktop or Docker Engine + Compose V2
- Python 3.10+ (tested on 3.12)
- PyYAML (install with: pip install pyyaml)

Getting Started
---------------
1) Clone the repo
2) (Optional) Create templates to customize defaults:
   - ./templates/env.default
   - ./templates/nginx/default.conf
3) Create and activate a virtual environment (optional but recommended)
4) Install PyYAML:
   pip install pyyaml
5) Bring up the stack (defaults to profile=full if no args):
   python orchestrator.py
   or
   python orchestrator.py up --profile full

Alternative entry:
   python -m orchestration up --profile full

Profiles
--------
- minimal: php, db, search
- full: php, db, search, nginx, redis

Note: A root-level profiles.py exists in the repo and includes a "test" profile, but the orchestrator uses the PROFILES defined in orchestration/constants.py. Prefer editing orchestration/constants.py for authoritative profiles.

Hybrid Configuration Model (Source of Truth)
--------------------------------------------
Preference order when generating runtime files on first run:

1) .env
   - Use ./templates/env.default if present
   - Else fallback to orchestration/constants.py::DEFAULT_ENV

2) Nginx default.conf
   - Use ./templates/nginx/default.conf if present
   - Else fallback to orchestration/constants.py::DEFAULT_NGINX_CONF
   - When generated from constants, a single-line marker is added at the top:
     # Generated by orchestration.nginx (constants fallback)

Non-destructive rule:
- Existing .env and nginx/conf.d/default.conf are never overwritten.
- If an existing nginx/conf.d/default.conf looks wrong, we warn only (no auto-repair).

.env Parsing Rules
------------------
- Unquoted values strip inline comments that begin after whitespace:
  DB_PORT=3316  # host:container -> 3316:3306
  -> DB_PORT = "3316"

- Quoted values preserve everything inside the quotes, including '#':
  PASSWORD="pa#ss"
  -> PASSWORD = "pa#ss"

Common Environment Variables
----------------------------
COMPOSE_PROJECT_NAME   Project prefix (containers, networks, volumes)
SITE_HOST              Host used for browser URL when Nginx is running (full profile)
APP_PORT               Host port that maps to Nginx :80 (e.g., 81 -> browse http://127.0.0.1:81)
DB_PORT                Host port for DB (e.g., 3316 -> host:3316 -> container:3306)
SEARCH_PORT            Host port for Search (e.g., 9201 -> host:9201 -> container:9200)
REDIS_PORT             Host port for Redis (e.g., 6381 -> host:6381 -> container:6379)
PHP_IMAGE              PHP-FPM image (must include Magento-required extensions if custom)
DB_IMAGE               Database image (e.g., mysql:8.0 or mariadb:10.6)
SEARCH_IMAGE           Search image (OpenSearch or Elasticsearch)
NGINX_IMAGE            Nginx image
REDIS_IMAGE            Redis image
MYSQL_ROOT_PASSWORD    DB root password (dev-safe default)
MYSQL_DATABASE         DB schema name (dev-safe default)
MYSQL_USER             DB user (dev-safe default)
MYSQL_PASSWORD         DB user password (dev-safe default)
SEARCH_JAVA_OPTS       Generic JVM heap options applied to the active search flavor
OPENSEARCH_JAVA_OPTS   Flavor-specific knob (used if generic not set and flavor is OpenSearch)
ES_JAVA_OPTS           Flavor-specific knob (used if generic not set and flavor is Elasticsearch)

What Gets Generated
-------------------
- .env
  Generated on first run from ./templates/env.default if present, else from constants.
  Existing .env is preserved.

- nginx/conf.d/default.conf
  Generated on first run from ./templates/nginx/default.conf if present, else from constants with a one-line generated marker.
  Existing file is preserved. If it fails a lightweight sanity check, a warning is printed but the file is left untouched.
  Note: The Magento static handler line is:
        try_files $uri $uri/ /static.php?resource=$uri&$args
        In rendered HTML contexts you might see &amp; but the file on disk uses &.

- ./src/index.php
  Created only if ./src is empty, with literal content: <?php phpinfo();

Basic Commands
--------------
Generate compose only (no containers started):
  python orchestrator.py generate --profile full

Bring the stack up:
  python orchestrator.py up --profile full

Bring the stack down (including named volumes):
  python orchestrator.py down

Show status (docker compose ps):
  python orchestrator.py status

Compose Output
--------------
- docker-compose.yaml is generated for the selected profile with explicit values inlined from .env
- Top-level "name" matches COMPOSE_PROJECT_NAME
- Named volumes are included only if referenced by services:
  - dbdata
  - searchdata
  - rediscache

Windows/WSL Notes
-----------------
- For fast bind mounts and reliable file watching, keep your repo inside your WSL distro (e.g., ~/projects/...) and run from a WSL shell.
- When using OpenSearch or Elasticsearch on Windows/WSL2, remember to set:
  vm.max_map_count=262144
  Example (PowerShell):
  wsl -d docker-desktop sysctl -w vm.max_map_count=262144
  Persisting this setting may require additional configuration.

Troubleshooting
---------------
- Can’t reach site in full profile:
  - Confirm Nginx is mapped to APP_PORT (default 81). Visit http://127.0.0.1:81/
  - Ensure ./nginx/conf.d/default.conf exists (it is created on first run or can come from templates)
  - Ensure php service name matches fastcgi_pass in Nginx (php:9000)

- Search engine fails to start:
  - Set vm.max_map_count=262144 (Windows/WSL)
  - Reduce JVM heap in .env via SEARCH_JAVA_OPTS (e.g., -Xms512m -Xmx512m)

- Permissions or file watch issues on Windows:
  - Move the project into your WSL distro and run from there

Acceptance Checks (Manual)
--------------------------
1) No templates present
   - Delete .env and nginx/conf.d/default.conf
   - Run the tool -> .env and default.conf are generated from constants
   - Confirm Nginx contains `/static.php?resource=$uri&$args`
   - Confirm default.conf starts with the generated marker

2) Templates present
   - Add ./templates/env.default and ./templates/nginx/default.conf with recognizable changes
   - Delete .env and nginx/conf.d/default.conf
   - Run the tool -> files are created from templates (not constants)
   - Re-run -> existing files are not overwritten

3) Inline comments
   - In .env: DB_PORT=3316  # host:container -> 3316:3306
   - Loader uses DB_PORT=3316 (comment suffix stripped)
   - Quoted values preserve '#': PASSWORD="pa#ss" -> value includes '#'

Project Structure
-----------------
.
├─ orchestrator.py                      Entry point that calls orchestration.main
├─ orchestration/
│  ├─ __init__.py                       Package entrypoint (main)
│  ├─ cli.py                            CLI arg parsing, preflight, dispatch
│  ├─ commands.py                       High-level commands (generate/up/down/status)
│  ├─ compose_builder.py                Compose dictionary builder
│  ├─ constants.py                      DEFAULT_ENV, DEFAULT_NGINX_CONF, PROFILES
│  ├─ env.py                            .env loader and ensure_env_file
│  ├─ nginx.py                          ensure_nginx_conf and ensure_src_stub
│  ├─ docker_cli.py                     Thin wrapper around `docker compose`
│  └─ utils.py                          logging, preflight checks, helpers
├─ templates/                           (optional) preferred defaults
│  ├─ env.default
│  └─ nginx/default.conf
├─ nginx/conf.d/                        Generated/used nginx configs (local)
└─ src/                                 Your Magento web root (stub index.php on first run)
